# Website-Traffic-Analysis
Website Traffic Analysis using Python, Pandas, Matplotlib and Seaborn.

## Project Overview
This project analyzes website traffic data to uncover visitor behavior patterns, peak traffic periods, and overall website performance.

The analysis was performed using Python, Pandas, Matplotlib, and Seaborn as part of a Data Analytics Internship project.

---

## Objectives

- Analyze website traffic trends over time
- Identify peak traffic hours
- Compare traffic across days of the week
- Detect high-traffic periods and patterns
- Generate actionable business insights

---

## Dataset Information

- Total Records: 2,793
- Features:
  - Timestamp
  - TrafficCount

## Analysis Performed

### Data Cleaning
- Checked for missing values
- Verified data types

### Exploratory Data Analysis (EDA)
- Website Traffic Over Time
- Traffic Distribution Analysis
- Average Traffic by Hour
- Average Traffic by Day
- Top Traffic Days Analysis

---

## Key Findings

### Traffic Statistics
- Maximum Traffic: 71,925
- Minimum Traffic: 22
- Average Traffic: 8,591
- Median Traffic: 2,418

### Hourly Insights
- Traffic begins increasing around 8 AM
- Peak traffic occurs between 10 AM and 2 PM
- Highest activity observed around 11 AM

### Weekly Insights
- Monday records the highest average traffic
- Tuesday–Friday maintain strong traffic levels
- Weekends show significantly lower traffic

### Traffic Pattern
- Traffic distribution is highly skewed
- A few high-traffic events contribute significantly to total visits

---

## Business Recommendations

1. Schedule marketing campaigns during peak hours (10 AM – 2 PM).
2. Prioritize promotional activities on weekdays.
3. Investigate high-traffic days to identify successful strategies.
4. Prepare website infrastructure for sudden traffic spikes.
